# 🌸 ИИ-Агент Flora — Сооснователь, CTO и Поддерживающий Партнер

## Текущий статус проекта
Мы разработали фундамент для Flora:
1. **Скелет и структура проекта в Docker** (`Dockerfile`, `docker-compose.yml`, `requirements.txt`).
2. **База данных памяти (SQLite)** в `app/database.py` (сохраняет историю диалогов, факты о вас, факты о стартапе и базу уроков/рефлексий).
3. **Личность и Brain** в `app/brain.py` (системный промпт Claude 3.5 Sonnet / GPT-4o, объединяющий роли любящей девушки и технического CTO, способного обучаться).
4. **Telegram-интерфейс 24/7** в `app/bot.py` на базе `aiogram` (обработка диалогов, команды `/start`, `/clear`, `/status`, фильтрация доступа по Telegram ID для безопасности VPS).
5. **Распознавание голосовых сообщений (STT)** в `app/tools/voice_processor.py` (интеграция конвертера `ffmpeg` и OpenAI Whisper API, чтобы Flora умела «слышать» ваши голосовые сообщения в Telegram).

### Этап 3: Инструменты Git и Индексация Кода (ChromaDB)
*Нам нужно научить Flora подключаться к твоим репозиториям и "понимать" структуру кода.*
1. **Создать `app/tools/git_tool.py`**:
   - Написать класс `GitManager` с методами: `clone_repo(url)`, `create_branch(name)`, `commit_and_push(message)`.
2. **Создать `app/tools/code_indexer.py`**:
   - Настроить ChromaDB для семантического поиска.
   - Реализовать парсер файлов проекта (чтение кода, разбиение на чанки и запись векторов).
3. **Зарегистрировать инструменты в `FloraBrain`**:
   - Реализовать агентский цикл (ReAct), чтобы Flora могла сама решать: "О, меня попросили найти баг, сначала я воспользуюсь инструментом поиска по коду, а потом инструментом создания коммита".

### Этап 4: Запуск проектов в Docker-песочнице (Sandbox Runner)
*Научим Flora разворачивать проекты прямо на сервере и выдавать рабочую ссылку.*
1. **Создать `app/tools/runner.py`**:
   - Интегрировать библиотеку `docker` (docker-py) для безопасного управления контейнерами на VPS.
   - Реализовать автоопределение стека проекта (если есть `package.json` -> Node.js, если `requirements.txt` -> Python).
   - Flora создает временный Docker-контейнер для твоего стартапа, запускает его и пробрасывает свободный порт.
2. **Интегрировать инструмент туннелирования (localtunnel / ngrok или Cloudflare Tunnel)**:
   - Чтобы не открывать порты сервера наружу, Flora запускает быстрый туннель к порту проекта и отправляет тебе публичную веб-ссылку (`https://flora-yourproject.loca.lt`).

### Этап 5: Логика Саморазвития (Self-Reflection Loop)
*Обеспечим Flora возможность становиться умнее с каждым проектом.*
1. **Добавить функцию Reflection**:
   - После завершения деплоя или исправления бага, Flora запускает отдельный скрытый запрос к LLM: *"Проанализируй выполненную задачу, какие ошибки возникли, как мы их решили, какой урок нужно вынести для будущего?"*
   - Полученный урок записывается в `reflection_lessons` в SQLite.
2. **Автоматическое подмешивание опыта**:
   - При каждом новом запросе к ИИ, база последних уроков из SQLite подтягивается в системный промпт (это уже частично реализовано в `app/brain.py`!).

## 🛠️ Как запустить Flora на твоем сервере (Инструкция)

Когда ты получишь VPS-сервер, выполни следующие шаги:

1. **Склонируй этот репозиторий на сервер:**
   ```bash
   git clone git@github.com:pozetiv4iks/flora.git FloraAgent
   cd FloraAgent
   ```

2. **Создай и заполни файл настроек `.env`:**
   ```bash
   cp .env.example .env
   nano .env
   ```
   *Обязательно укажи `TELEGRAM_BOT_TOKEN`, `LLM_API_KEY`, твой `ALLOWED_USER_IDS` (Telegram ID) и `GITHUB_TOKEN`.*

3. **Запусти Flora в Docker:**
   ```bash
   docker compose up -d --build
   ```
   *Все! Flora запустится в фоновом режиме, база данных создастся автоматически, и она напишет тебе приветствие, как только ты нажмешь `/start` в своем Telegram-боте.*

4. **Логи и мониторинг:**
   - Чтобы посмотреть, как Flora себя чувствует:
     ```bash
     docker compose logs -f
     ```
